# Linux 实测与补丁

基线为 Ubuntu 22.04、GNOME 42.9、X11、x86_64。上游版本 computer-use-linux v0.5.0，
MIT。本包保留源码归属、许可证与补丁，不代表上游已接受这些修改。

已验证：截图和窗口裁剪、单击/双击/右键、悬停、四向滚动、连续拖拽、Ctrl+A、
中文输入、AT-SPI 语义操作、窗口相对坐标、透明可见鼠标反馈。15 步一次性 GTK
控件验收通过。ZCode 中另有完整收发和两轮同会话续聊的实际验证。

补丁解决的实际问题：

- 旧 ATK bridge 的 Action.GetActions 会崩溃，改为 NActions 属性和逐项动作读取。
- wmctrl 坐标偏移导致裁剪和点击错位，使用 xwininfo 的实际 client root 坐标。
- 指针层需设置 GTK widget 的空 input shape，避免吞掉后续点击。
- X11 中文临时键映射在 0/12ms 间隔丢字，使用 50ms 和随输入长度增加的超时。
- 截图包含鼠标；添加可见悬停、四方向滚动及连续拖拽。

原始失败被保留在作者机器，未冒充成功。浅层焦点诊断仍可能误报，完整树及文本
回读是验收依据。当前没有 Wayland、ARM、其他桌面或任意文本长度的可靠性结论。
